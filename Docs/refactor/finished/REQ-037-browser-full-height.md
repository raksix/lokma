# REQ-037 — Browser içeriği kesik kalıyor, full height olsun

- **Status:** done (live 2026-09-07 — implemente edildi, headless ölçüm + bundle-match kanıtlı)
- **Asked:** 2026-09-07 — "browser kesik kalıyor, full height olsun ya" (+ ekran görüntüsü: browser pane'de içerik üstte kalıyor, altta büyük boşluk).
- **Interpretation:** Browser pane içeriği (iframe/preview) pane yüksekliğinin tamamını doldurur — alttaki boşluk kalkar. Şüpheliler: içerik kapsayıcısında sabit yükseklik / `flex-1` eksikliği / iframe'e height verilmemiş olması. REQ-013 (browser sadeleştirme) ile birlikte ele alınabilir.
- **Touched (plan):** browser pane içerik kapsayıcısı (flex column + `flex-1 min-h-0`, iframe `h-full`).
- **Verify (plan):** root+web `tsc` 0, web build green, single-proc restart, headless ile içerik kutusunun pane yüksekliğine eşit olduğu ölçümle kanıtlanır, bundle match.
- **Fix:** Kök neden yapısaldı — `BrowserPane` root + içerik alanı `flex-1` idi ama hiçbir host gerçek yükseklik vermiyordu: tiling tab wrapper blok (`h-full overflow-auto`, flex değil), sidebar/mobil Inspector ise sınırsız yükseklikli kayan kolon. Üç yere dokunuldu: (1) `browser-pane.tsx` root + içerik alanına `min-h-0` (flex column'da büzülme güvenliği) + full-height kontratını belgeleyen yorum; (2) `inspector-host.tsx` tiling browser dalı `flex h-full min-h-0 flex-col overflow-hidden` kabuğuna alındı (diğer tab'ların kayan wrapper'ı aynen durur); (3) `inspector-panel.tsx` sidebar/mobil browser dalı `flex h-[60vh] min-h-[320px] flex-col overflow-hidden` kabuğuna alındı. iframe zaten `h-full` idi. Tüm sınıflar tam-literal (dinamik `border-${x}` yok), lucide aynen.
- **Proof:** root `tsc --noEmit` 0 hata, web `vite build` green (`index-MF75KEtv.js`), single-proc lokma-web restart online (uptime sıfırlandı), served==disk BUNDLE-MATCH (canlı demette `h-[60vh]` doğrulandı), headless PASS 0 pageerror — sidebar: kabuk 480px (=60vh) + iframe 439px (=480−41 toolbar); tiling: tab gövdesi 540px + iframe 499px (=540−41 toolbar).
