## Overall

A single full‑bleed dark IDE‑style window (Lokma) in a 16:9 desktop frame. Everything is near‑black with hairline separators; the only saturated colour is a warm orange/amber accent plus a few green status dots. The window is split into **six vertical bands**: icon rail → session sidebar → chat column → browser column → collapsed right dock → bottom status bar.

## Colour summary

| Role | Colour |
|---|---|
| Window background | near‑black `#0b0b0d` |
| Panel / sidebar / cards | one to three steps lighter, `#131316`–`#1c1c20` |
| User bubble fill | mid dark grey `#2a2a2f` |
| Hairline borders/dividers | `#26262b` |
| Primary text | white / `#f2f2f4` |
| Secondary text | mid grey `#8b8b93` |
| Hint / placeholder | dim grey `#6e6e76`, monospace for ids and URLs |
| Accent (active rail icon + edge bar, Thinking Max outline, floating dot) | orange/amber |
| Send button | rust / warm brown |
| Status (2.7k dot, address‑bar dot, active session dot, gateway dot) | green |
| Logo pill & agent avatar | pure white with black `L` |
