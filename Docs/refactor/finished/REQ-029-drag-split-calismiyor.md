# REQ-029 — Session sidebar'dan pane'e sürüklenince split yapmıyor

- **Status:** done 2026-09-07 (implemented + live-verified, see Proof)
- **Asked:** 2026-09-07 — "session chati sidebardan alıp pane için sürüklüyorum, pane split yapmıyor aq. onları falan da düzeltmemiz lazım".
- **Interpretation:** Session satırı pane üzerine (özellikle kenarlara) bırakılınca split gerçekleşmiyor. Şüpheliler (uygulamada doğrulanacak): `WorkspacePane.handleDrop` + `dropZoneFor`/`splitForZone` kenar hesabı, `onDragOver`'da `hasPanePayload` engeli, drop koordinatının pane body dışına düşmesi, `SessionDropChooser`'ın split aksiyonu (`openSplit`) kablosu. Beklenen: kenara bırakınca split + yeni pane'de session açılır, ortaya bırakınca chooser gelir.
- **Touched (plan):** `components/panes/pane.tsx` (drop/zone/split akışı), gerekiyorsa `panes.ts` zone hesabı.
- **Root cause (verified):** TWO defects. (1) `onDragOver` answered every dragover with hardcoded `dropEffect='move'`, but session/file rows drag with `effectAllowed='copy'` — Chrome enforces the pair and silently rejects the drop (no `drop` event fires at all). Rails/tabs (`'move'`) worked, which is why only session/file drops died. (2) The tab strip had NO drop handlers — drops aimed at the top of a pane (the natural edge target) hit an element without `preventDefault` and were lost, unlike concept `handleTabBarDrop`.
- **Fix:** NEW pure `dropEffectFor(effectAllowed)` in `panes.ts` (copy stays copy, move/copyMove/linkMove/all/uninitialized allow move, link stays link) used by both body and tab-strip `onDragOver`; `handleDrop` takes optional `forcedZone`; `PaneTabBar` is now a drop target delegating with `'center'` (open/chooser, never split — concept parity) + terracotta hover tint, all literal Tailwind classes.
- **Proof:** panes probe 95/95 (8 new `dropEffectFor` asserts); root `bun x tsc --noEmit` 0; web build green `index-B5k5OIkd.js`; single-proc lokma-web restart online; served bundle == disk dist (BUNDLE-MATCH); headless CDP `dragTo` PASS — 3 panes + 16 session rows, row dragged to right-edge band (88% x) → 4 panes, no chooser, 0 pageerrors.
- **Verify (plan):** root+web `tsc` 0, web build green, single-proc restart, headless CDP drag ile kenara drop'ta split + yeni pane'de session tab'ı kanıtlanır, bundle match.
