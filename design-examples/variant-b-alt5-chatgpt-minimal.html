Let's refactor the auth middleware. I want to move the JWT verification into a Fastify preHandler hook so every route can opt-in with a single decorator. Keep it framework-native — no extra deps.

◐ Lokma Claude 4 Sonnet 14:32 · 1.2s Applied to inspectable trace

Perfect — cleanest approach. One hook, one decorator, zero magic.

plugins/auth.ts 
// Fastify preHandler — opt-in per route
import fp from 'fastify-plugin'
import { verifyJwt } from './jwt'

export default fp(async (app) => {
  app.decorateRequest('user', null)

  app.addHook('preHandler', async (req, reply) => {
    if (!req.routeOptions.config?.auth) return
    const token = req.headers.authorization?.replace('Bearer ', '')
    if (!token) return reply.code(401).send({ error: 'missing token' })
    req.user = await verifyJwt(token)
  })
})

// usage
app.get('/me', { config: { auth: true } }, async (req) => req.user)
No new deps · typed · runs only when config.auth is set

Why this works

  • Framework-native. Uses Fastify's own hook system — no wrapper, no hidden state.
  • Opt-in per route. Only routes that set config.auth pay the cost.
  • Inspectable. Attaches to request.user — visible in every log.
