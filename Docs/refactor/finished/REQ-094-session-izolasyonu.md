# REQ-094 — Session'lar kullanıcıya özel olsun (admin dahil)

- **Status:** done (canlıda — 2026-09-09)
- **Asked:** 2026-09-09 — "sessionlar her kullanıcı için ayrı session olsun, adminin bile sessionları ayrı olsun, diğer kullanıcıların sessionunu görmesin".
- **Teşhis (koddan):** bugün `GET /api/sessions` `canViewSession` ile filtreleniyor (`sessions.ts:128`), `ownerId` create/fork'ta damgalanıyor. Ama: (1) admin/superadmin HERKESİ görür, (2) sahipsiz (unattributed) eski session'lar calisan'a görünür. İstek sıkı izolasyon: kimse başkasının session'ını görmez, admin dahil. Karar (dosyadaki varsayılan uygulandı): tam izolasyon + sahipsiz session'lar yalnız superadmin'e görünür (temizlik için); ayrı admin "denetim modu" açılmadı.
- **Fix:** çekirdek `canViewSession` tek noktada sıkılaştı (`ownerId == user.id`, her rol; sahipsiz/meta-yok yalnız superadmin) — liste/arama/oku/fork/patch/delete/merge/rewind/run hepsi otomatik devralır. `meta &&` kısa-devreleri koşulsuz kontrole çevrildi (meta-yok = sahipsiz). Korumasız `compaction` GET (404) + POST (403) beklendi. WS handshake чужой socket'i 4403 ile kapatır + prompt yolu her tur sahiplik doğrular (yoksa `forbidden`, transcript'e yazılmaz — sahipsiz-dosya fabrikası kapandı). Gate-off davranışı değişmedi (legacy-open). `roles.test.ts` matrisi yeni kurala çevrildi (13 izolasyon assert'i).
