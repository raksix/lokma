# REQ-015 — Pane üstündeki tablar seçilemiyor, tab sistemi düzgün çalışmıyor

- **Status:** done (2026-09-07, live verified — see Proof below)
- **Asked:** 2026-09-07 — "bu panein üstündeki şeyler seçilmiyor, düzgün çalışmıyor amk, pane içinde tab sistemi işte düzgün çalışmıyor" (+ ekran görüntüsü: pane tab strip — Browser / session / file tabları + X butonları).
- **Note:** Görselde şerit düzgün görünüyor (hizalı, taşma yok) — sorun davranışsal: tıklayınca aktif tab değişmiyor. Şüpheliler (uygulamada doğrulanacak): tab tıklamasının drag/split handler'ları tarafından yutulması, `onSelect` kablosu, `data-pane-tab` closest kontrolü (`onDoubleClick` maximize ile çakışma).
- **Touched (plan):** `components/panes/pane.tsx` (`PaneTabBar` tıklama/drag kabloları).
- **Verify (plan):** root+web `tsc` 0, web build green, single-proc restart, headless ile her taba tıklanıp aktif içeriğin değiştiği + X ile kapandığı kanıtlanır, bundle match.
- **Proof:** root cause was a stale `useMemo`, not the click wiring: `TilingWorkspace` rendered `ensured.states` but the memo deps were `[paneIds, sessionId]` — `tabStates` missing — so every `setTabStates` (tab select, tab add, tab close) updated state that was never read back; the strip re-rendered the old active tab and the picker never showed new tabs (verified live: `tabsChange` fired with the correct 2-tab payload yet DOM + localStorage stayed at 1 tab, no error, no remount). Fix: memo deps `[paneIds, sessionId, tabStates]` (no loop — the ensured effect only writes when a pane is missing). Defense in depth on the tab strip itself: select on `onMouseDown` (a `draggable` tab turns any press with a few px of movement into a `dragstart`, so `click` never fires) keeping `onClick` as fallback, plus `role=tab`/`aria-selected`/`tabIndex` + Enter/Space and `role=tablist` on the strip. Gates: web `tsc --noEmit` 0, web build green `index-BOrPu4kL.js`, single-proc `lokma-web` restart online, served bundle == disk dist with `tablist` marker live, headless xvfb Chromium PASS (picker opened Info + Providers tabs, mousedown on inactive tab flips `aria-selected`, Enter flips it back, 0 pageerrors).
